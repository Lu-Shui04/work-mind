# 财务付款与预算管理办法

**文件编号**：CW-2026-005　**发布部门**：财务部　**生效日期**：2026-01-01　**版本**：2026-09
**适用范围**：各部门负责人、采购经办人、全体报销人

## 一、预算管理

1. 公司实行**年度预算 + 季度滚动**管理，每年 11 月编制次年预算，按部门下达。
2. 部门在预算内自主安排支出；单笔支出超过部门季度预算 10% 的，须提前报财务部备案。
3. 超预算处理：

| 超预算幅度 | 审批要求 |
|-----------|---------|
| 10% 以内 | 部门负责人审批，财务部备案 |
| 10% - 30% | 财务负责人（CFO）审批 |
| 30% 以上 | 总经理办公会审议 |

4. 未经审批的超预算支出，财务部有权拒绝付款。

## 二、付款流程

1. 标准付款流程：**合同/订单 → 验收确认 → 取得发票 → 提交付款申请 → 审批 → 付款**。
2. 付款申请须在 OA 提交，附件包括：合同扫描件、验收单、发票、付款申请单。
3. 无合同的小额采购（单笔 2000 元以内）可由部门负责人在 OA 直接申请，注明用途与供应商。
4. 付款审批权限：

| 单笔金额 | 审批人 |
|---------|--------|
| 5000 元以内 | 部门负责人 |
| 5000 - 50000 元 | 部门负责人 + 财务负责人 |
| 50000 - 200000 元 | 财务负责人 + 总经理 |
| 200000 元以上 | 总经理 + 董事会授权人 |

## 三、付款周期

1. 标准账期为**月结 30 天**，付款日为每月 **25 日**；遇节假日顺延至下一工作日。
2. 付款申请须在付款日前 **5 个工作日**提交至财务部，逾期顺延至下一付款日。
3. 预付款原则上不超过合同金额的 30%，超过 30% 的须说明理由并经财务负责人批准。

## 四、发票管理

1. 发票抬头必须为公司全称，纳税人识别号必须准确；个人抬头发票不予报销或付款。
2. 增值税专用发票须在开票后 30 日内提交财务认证，逾期造成无法抵扣的，由责任人承担损失。
3. 严禁虚开发票、拆分发票规避审批权限。一经查实，按公司制度严肃处理并追究法律责任。

## 五、备用金与借款

1. 因公需要可申请备用金，单人未清备用金余额不得超过 5000 元。
2. 备用金须在事项结束后 15 个工作日内核销，未核销的从当月工资中暂扣。
3. 员工离职前必须完成全部借款与备用金清算。

## 六、附则

本办法由财务部负责解释。与《差旅与报销管理制度》不一致的，差旅费用部分以《差旅与报销管理制度》为准。
